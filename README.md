A personal portfolio website developed to showcase my education, projects, technical skills and experience.
The website also includes a database-backed blog system with user authentication and content management.

The project contains PHP files responsible for database connections, authentication, blog management and page generation, alongside HTML, CSS, JavaScript and image assets.

The HTML files do not require the database and you can see the project through these. If you want to look at the blog posts and the functionality the XAMMP app is needed.

The project uses a MySQL database hosted locally through XAMPP.
The database is used to store and retrieve blog posts and user authentication information.

Running the project:
1.Install XAMPP
2.Start Apache and MySQL through the XAMPP Control Panel
3.Open phpMyAdmin by navigating to http://localhost/phpmyadmin
4.Create a database named portfolio
5.Place the project folder inside the XAMPP htdocs directory
6.Open the project in a browser through http://localhost/project-folder

Note: The database tables must be created in phpMyAdmin before the database-backed features can be used.
